# 📚 Aula Circular

> 🌱 Plataforma web para la **gestión y reutilización de recursos educativos**.

**Aula Circular** es una aplicación web responsive ccuyo objetivo es centralizar la biblioteca del centro, facilitar la cesión, préstamo e intercambio de libros entre alumnado y organizar la documentación académica.

## ✨ Funcionalidades

* 🏠 **Inicio** — Registro, acceso y novedades.
* 📚 **Biblioteca** — Recursos físicos, digitales y enlaces.
* 📖 **Libros** — Cesión, préstamo e intercambio entre estudiantes.
* 📄 **Documentación** — Requisitos, listas y plantillas por curso.
* 👤 **Mi espacio** — Perfil, publicaciones, solicitudes, préstamos e historial.
* 👩‍🏫 **Panel docente** — Validación de cuentas, reservas, entregas y devoluciones.
* ⚙️ **Administración** — Gestión de usuarios, roles, cursos y categorías.

## 🛠️ Tecnologías

| Tecnología       | Uso                       |
| ---------------- | ------------------------- |
| 🌐 HTML5         | Estructura                |
| 🎨 CSS3          | Diseño responsive         |
| ⚡ JavaScript     | Interactividad y frontend |
| 🟢 Node.js 24    | Backend                   |
| 🚂 Express 5     | API y servidor            |
| 🐘 PostgreSQL 17 | Base de datos             |
| 🔀 Git           | Control de versiones      |

El proyecto utiliza **HTML, CSS y JavaScript sin frameworks de cliente**, junto con Node.js + Express y PostgreSQL.

## 🎯 Objetivos

* ♻️ Favorecer la reutilización de materiales educativos.
* 🔐 Gestionar usuarios y permisos de forma segura.
* 📱 Crear una interfaz usable desde **320 px**.
* 🔄 Gestionar préstamos, cesiones e intercambios.
* 🧪 Aplicar pruebas y validaciones sobre los diferentes recorridos.
